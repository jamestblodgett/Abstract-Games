About

This site is a collection of simple games with an abstract design.

NOT part of the class of games called "Abstract Games", this site does NOT have chess or checkers.

All of these games are fun, simple games that I hope you're able to enjoy.

Versions

The versions are organized as such:

1.1.2

1(total game updates, biggest, 2 would be a sequel).1(new games and big updates for individual games, .2 would be a new game).2(minor game updates and bug fixes, .3 would be a change to the shapes game).
